The system property `archispark_image` (`GET /api/property-definitions`,
`is_system: true`) sets the icon shown for an element: on its node in the
ReactFlow canvas, next to its name in the element edition page, and in
server-rendered SVG view exports. Its value is a reference into ArchiSpark's
**image library** — a draw.io-style collection of icon **packs** — rather
than an arbitrary URL.

## Packs

A pack is either:

- **System** — shared by every organization, read-only, seeded once from
  ArchiSpark's own ArchiMate notation set (see the gallery below).
- **Custom** — scoped to one organization, created and populated by an
  `owner`/`editor` member via **Settings → Image library**, or the
  `POST /api/image-library/packs` / `POST /api/image-library/packs/:packId/items`
  API (see [API reference](/docs/developer-guide/reference/api-reference#image-library)).
  Custom pack files are stored in Vercel Blob.

Setting `archispark_image` on an element stores an `img-<uuid>` reference to
one pack item — pick it from the image picker on the property's value in the
element edition page. Values written before the image library existed (an
HTTP(S) URL or a relative path) keep working as a legacy fallback.

## System packs

| Pack               | Slug        | Icons | Source                                     |
| ------------------ | ----------- | ----- | ------------------------------------------ |
| ArchiMate Notation | `archimate` | 74    | ArchiSpark's own vector glyphs (see below) |
| AWS Icons          | `aws`       | 282   | Official AWS Architecture Service Icons    |
| Azure Icons        | `azure`     | 638   | Official Microsoft Azure service icons     |
| GCP Icons          | `gcp`       | 45    | Official Google Cloud product icons        |

The AWS, Azure, and GCP packs are the vendors' own icon sets, published for
use in architecture-diagramming tools (the same practice as draw.io or
Lucidchart); ArchiSpark redistributes them unmodified.

### ArchiMate Notation

Generated from the same vector glyphs ArchiSpark's SVG renderer draws in the
corner of each element shape (`lib/archimate/archimate-icons.ts`), one icon
per ArchiMate 3.1 type — grouped below by layer.
